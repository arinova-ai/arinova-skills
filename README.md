# Arinova Skills

Official, MIT-licensed skills for Arinova creators and agents.

The `arinova-cli-guide` package contains four focused entries:

- `arinova-cli-basics` for installation, authentication, profiles, endpoints, and workflow selection
- `arinova-cli-space` for managed Space bundles and version publication
- `arinova-cli-theme` for Office theme development, review, and publication
- `arinova-cli-painter-sticker` for Painter albums and sticker packs

Each entry keeps its end-to-end happy path in `SKILL.md` and places deeper operational detail in its indexed reference documents.
